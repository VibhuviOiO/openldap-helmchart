openldap

A Helm chart for running vibhuvioio/openldap on Kubernetes as a multi-provider (N-way multi-master) OpenLDAP cluster.

This URL is a Helm chart repository. It has no web pages by design — the files here are index.yaml and the packaged charts. Install from it:

helm repo add vibhuvioio https://VibhuviOiO.github.io/openldap-helmchart
helm repo update
helm install ldap vibhuvioio/openldap -n directory --create-namespace \
  --set auth.existingSecret=ldap-auth
